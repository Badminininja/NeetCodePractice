# NeetCode Practice

Solutions to LeetCode/NeetCode-style problems, worked through conversationally with Claude to recover coding fluency.

Each solution is committed after we work through the problem together — tracing bugs, testing edge cases, and refining the approach.

## Structure

`solutions/<N>-<category>/` — one file per problem, named `NN-problem-name.py`. Category folders are numbered by roadmap order (a DFS over neetcode.io's roadmap graph — a branch that dead-ends gets numbered before the traversal continues down the surviving path; ties broken left to right):

1. Arrays & Hashing
2. Stack
3. Two Pointers
4. Sliding Window
5. Binary Search
6. Linked List
7. Trees
8. Tries
9. Backtracking
10. Heap / Priority Queue
11. Intervals
12. Greedy
13. Graphs
14. Advanced Graphs
15. 1-D Dynamic Programming
16. 2-D Dynamic Programming
17. Bit Manipulation
18. Math & Geometry

See `PROGRESS.md` for a running log of what's been solved and what was learned along the way.
