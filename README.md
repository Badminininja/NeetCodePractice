# NeetCode Practice

Solutions to LeetCode/NeetCode-style problems, worked through conversationally with Claude to recover coding fluency.

Each solution is committed after we work through the problem together — tracing bugs, testing edge cases, and refining the approach.

## Structure

- `solutions/<category>/` — one file per problem, named `NN-problem-name.py`, grouped into folders matching the NeetCode roadmap categories (Arrays & Hashing, Two Pointers, Sliding Window, Stack, Binary Search, Linked List, Trees, Tries, Heap / Priority Queue, Backtracking, Graphs, Advanced Graphs, 1-D DP, 2-D DP, Greedy, Intervals, Math & Geometry, Bit Manipulation).
